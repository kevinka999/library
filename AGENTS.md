# Library Repository

This repository groups two independently run applications: `library-api` contains the .NET backend and `library-web` contains the React frontend.

- Work only in the application placed in scope by the task; do not change the other application unless the task requires a coordinated change.
- Follow the closest application-level `AGENTS.md` when one exists.
- Design agent-facing documentation for progressive disclosure: keep always-loaded instructions small and information-rich, link to focused documents for conditional details, and avoid duplication that wastes context.
- Keep commits focused and use `type(project): description`, where the project scope is `api` or `web`.
