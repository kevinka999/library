# Library

This repository is not intended to be a monorepo. It simply groups two separate projects:

- `library-api`: .NET Core controller-based API backend.
- `library-web`: React frontend.

Each project must be run separately. Setup and usage instructions are available in the respective project directory.

## Commits

Commits should follow the `type(project): description` format, using the project as the scope:

- `feat(api): add book search`
- `feat(web): add book search page`
