# Library API

This is a .NET 10 controller-based API for managing books and their immutable change history.

- Read `CONTEXT.md` before changing domain concepts, rules, or terminology.
- Read `docs/domain/BOOKS.md` before changing Book behavior or history semantics.
- Read the relevant records under `docs/adr/` before changing architecture or persistence.
- Read `docs/ARCHITECTURE.md` before changing project references, component boundaries, controller responsibilities, or persistence abstractions.
- Run `dotnet build` after code changes and `dotnet test` after behavioral changes.
- Update the relevant documentation when a change makes it inaccurate.
